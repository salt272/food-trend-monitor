Privacy Policy

Effective date: September 23, 2026

1. About this tool

Food Trend Monitor is an internal research tool operated by the AI Lab of Nongshim Co., Ltd. It tracks food trends in public YouTube content for Nongshim's marketing and product planning teams. It is not offered to the public.

2. Use of YouTube API Services

This tool uses YouTube API Services. By using or viewing content from this tool, you agree to be bound by the YouTube Terms of Service. YouTube data is also subject to the Google Privacy Policy.

3. What data we access

We read only public data through the YouTube Data API using an API key. We do not use YouTube or Google sign-in, do not request access to anyone's account, and do not access private data. The data we read is:

  • Public channel information and statistics (channel name, subscriber count, video count) for about 630 food creator channels.
  • Public video information and statistics (title, description, publish date, duration, view, like and comment counts).
  • Public comments on selected videos, including the commenter's public display name and public channel ID as returned by the API.

4. How we use the data

We use the data to measure how fast videos and topics are growing and to understand, in aggregate, which dishes and products are gaining attention in which markets. Results are shown to internal staff as aggregated figures (for example topic counts, growth rates and language shares). We do not build profiles of individual people, contact commenters, or use the data for advertising.

5. Storage and deletion

  • Public statistics (view, like, comment and subscriber counts) are stored as weekly snapshots to measure growth over time, for up to 36 months, in line with the YouTube API Services policy on derived metrics.
  • Other YouTube data (titles, descriptions and comment text, including commenter names) is kept for no longer than 30 days. Within that period it is either refreshed from the API or deleted. Comment text is analyzed within 30 days, after which only aggregated results that do not identify anyone are kept.
  • Derived metrics we calculate (such as growth rates and topic counts) are labeled as our own calculations.

6. Sharing

We do not sell, rent or share YouTube data with third parties. Aggregated findings are used only inside Nongshim.

7. Cookies and this website

This website is a static information page. It does not use cookies, analytics or tracking, and it does not collect any information from visitors.

8. Your choices
